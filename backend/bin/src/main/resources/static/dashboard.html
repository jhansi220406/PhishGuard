Core Security Recommendations

Beware Lookalike Domains

Phishers substitute letters with numbers (e.g. paypa1.com) or Cyrillic homoglyphs. Always inspect domain spelling closely.

Never Trust Naked IP Hosts

Legitimate customer portals never ask you to authenticate against a raw IP address (e.g. http://192.168.1.1/login).

The HTTPS Padlock Fallback

Over 80% of phishing sites now use free SSL/TLS certificates. HTTPS encrypts the connection, but does not guarantee honesty.
